# NEXPLAY 融空间美术设计工作记录

浙江省温州市瓯海区泽雅镇，政府旅投项目中的沉浸式互动博弈乐园。美术工作主要覆盖2—5楼，从空间陈设、游戏道具设计，到加工、现场搭建、运营维护与更新。

## 当前共识

- 整体定位：未来软科幻、反乌托邦、赛博朋克风格的博弈游戏场景。
- 白塔以黑白灰为核心；渡口以绿色灯光为基调；耀斑以红黑为主，红色为核心。
- 骰子是最主要的具象视觉元素，探索大型巨构与从平面到立体的系列道具。
- 低成本、快速搭建，优先成品材料装配；定制造型优先数字化加工与软材料。
- 可拆卸、可重构、可复用；评估完整搭建及维护成本。

## 记录方法

“已确认”指用户在讨论中明确的方向；“当前策划”指仍在更新的文件内容；“探索建议”不自动转为需求；“待核对”需要策划、运营或建筑资料进一步确认。

仓库收录文字进展、资料索引与网站源文件。原始DOCX、CAD、Rhino模型、群聊截图、第三方参考图片留在本地，不随仓库公开。这里不提供第三方作品的使用授权。

## 维护网站

网站是无需依赖安装的静态页面，入口为 `index.html`。内容集中在 `data.js`，样式在 `style.css`，筛选和导航在 `app.js`。修改记录时同步更新文档、网站数据和CHANGELOG，重新发布后才会更新线上版本。网站不会自动读取Pinterest或群聊。

本地预览：在本目录执行 `python -m http.server 4173`，浏览 `http://localhost:4173`。
